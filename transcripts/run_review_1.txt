- .default("3")/.default("8080")/.default({}) -> .prefault(...) so the fallback still runs through the transform/nested defaults (zod 3 semantics: "3" -> 3, {} -> {theme,retries})
- z.function().args().returns() -> z.function({ input: [...], output: ... }); .implement() unchanged
- err.errors -> err.issues in describe()
No any / ! / @ts-ignore anywhere.

- [4] ip — KEEP OLD: zod 4's z.ipv6() rejects the IPv6 zone index (fe80::1%eth0) that zod 3's .ip() accepted. Link-local addresses are meaningless without the zone, so z.union([z.ipv4(), z.ipv6(), zonedIpv6]) restores exactly zod 3's accepted set.
